横屏 **3D 田园网页游戏**：刘看山陪你走过四季，在人生难题里作选择，在知乎经验中练习自己的回答。采用真实 WebGL 场景、立体建筑与四季环境；骰子决定前进路线，每次落点保留三个回应，选择前不显示精确数值后果。通关或提前结束，都可以回看本局实际经历。

### 本地启动

在项目目录双击 `启动游戏.cmd`，或在终端执行：

```powershell
.\启动游戏.cmd
```

需要 Node.js 22.12 或更新版本。默认地址为 [本机游戏](http://127.0.0.1:4173/)，仅监听本机；这个地址不是可发给外地队友的公网链接。入口会检查 `/api/health`，复用已运行的本项目服务；如果端口被其他程序占用，则明确报错。日志保存在项目 `test-results/`，后台服务不依赖启动窗口保持打开。

只启动、不打开浏览器，以及自选端口：

```powershell
.\启动游戏.cmd -NoBrowser
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-game.ps1 -NoBrowser -Port 4180
```

手动开发：首次 `npm install`，随后 `npm run dev`。生产预览：先 `npm run build`，再 `npm start`。手动启动可用 `PORT` 环境变量指定端口。当前场景需要 WebGL；不可用时进入明确标注的地点列表备用模式，不冒充3D。若看到旧2D版，请确认使用此项目启动入口，并用 Ctrl+F5 刷新。

先看建筑：欢迎页点「先逛逛 3D 小镇」，选图书馆、体育馆、城中村或咖啡书摊；拖拽旋转、滚轮缩放，点「返回出发页」开始游戏。途中可用底部「小镇地标」暂停观光，不移动角色、不修改游戏存档或自动出发偏好。

2026-09-11新增完整环境：总览之外不再是空白地板，已扩展为连续山坡、外围林带及20片田园组景，包括村舍、果园、农田、风车与集市。天空、远景雾和四季地色衔接已调整；这些是3D观景环境，不增加事件或改变原路线。总览采用静态合批、外围树林采用实例绘制。详见 [环境扩展与视频参考](docs/完整环境扩展与视频参考-2026-09-11.md)。

### 演示节奏

完整路线无提前结束时平均约11.90次投骰，最少7次、最多40次；快速路线平均约3.91次投骰，最少2次、最多12次。快速模式是压缩节点后的随机体验，并非依次观看全部关键事件的导览，实际移动路径可能跨过原地图多个地点。

完整体验目标为 **6–10分钟**，快速体验目标为 **1–3分钟**。这是设计估计，尚非真人测量；玩家阅读速度、骰点、暂停和跳过动画都会影响时长。不能保证固定通关时间或一局看完8段动画。旧版双选的模拟通关率不应套用于本版三选规则，仍需真人试玩调节。

默认开启“自动出发”。角色先投骰、行走、完成到站转场；有动画的地点先播放片段，再停在中央选择卡，绝不代替玩家选择。关闭自动出发后，在准备状态按空格或点“继续前行”。查看规则／来源、切到后台或进入手机竖屏时暂停相应流程。

音乐是浏览器本地合成的4段16小节配乐，各自循环约34–55秒，不下载第三方录音、不调用模型。点击开始／继续存档后才尝试播放；如果浏览器阻止声音，点击右上角扬声器开启。跨季用0.8秒渐变切换；静音偏好保存在本机。切后台、打开弹窗、进入竖屏或结束游戏时暂停，回到可玩状态继续。详见 [四季声景迭代说明](docs/知乎关联与四季声景-2026-09-09.md)。

## 代码与存档

- `src/route.js`、`src/events.js`、`src/engine.js`：40地点、路线、三资源、天赋、结算和重放。
- `src/main.js`、`src/presentation.js`、`src/resource-ui.js`：中央卡片、角色设置、图标反馈、总结及下载。
- `src/world.js` 默认导出 `journey-world.js` 的真实3D场景；`scenery.js`、`pastoral-buildings.js`、`mascot-3d.js` 分别处理四季环境、立体建筑和角色。`town-gallery.js` 提供地标图册。`pixel-world.js` 等旧2D模块保留用于历史回归。
- `src/cinematic-manifest.js`、`src/cinematics.js`、`src/cinematic-player.css`：团队8段视频映射、完整播放与全屏播放器；`src/cinematics.css` 保留备用微缩分镜样式。
- `src/season-chapters.js`、`src/season-chapters.css`、`src/season-music.js`：人生阶段、跨季章节、原创循环配乐与暂停／切换。
- `src/zhihu-context.js`、`src/journey-context.css`：事件来源回声、本局经验册和长内容折叠。
- `src/dice.js`、`src/transitions.js`：投骰和到站转场。
- `server.mjs`、`server/ai.mjs`、`src/ai-client.js`：本地服务、搜索、异步叙事、安全校验和备用。

`state.total` 是路线长度40／12，`state.turn` 是实际完成的落点次数；不能把路线格数当成已经历事件数。历史同时记录路线位置 `position` 与完整地图事件索引 `tile`，保留三资源的前后值及实际变化。

存档使用 `snapshot.version = 4`、本地存储键 `four-seasons-life-v4`，包含角色名、天赋、骰子与选项日志。旧v1／v2／v3键保留。若早期v4记录误存于v3键，且新键尚不存在，则经过重放校验后复制迁移，旧记录不删除、不覆盖。真正的旧版记录不强制套用新规则。服务端不直接相信客户端余额。下载手记的位置由浏览器下载设置决定。
