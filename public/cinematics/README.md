## 导入与保护

在项目根目录运行：

```powershell
node tools/import-team-cinematics.mjs
```

该工具仅读取已明确批准的桌面“动画”文件夹中的8个固定文件名，输出到 `public/cinematics/team-20260912/`。运行依赖本机ffmpeg/ffprobe路径；跨机器使用前应先核对工具中的输入与依赖位置。它不会下载素材、调用模型、修改桌面原片或替换上一版视频。

导入先在非公开临时目录完成转码、整片音视频解码、帧数、时长、音轨、来源元数据、faststart及原片哈希检查，全部通过才发布媒体目录。证据位于 `test-results/team-cinematics/media.json`，接触图位于同一证据目录。已有输出和报告一致时仅校验并跳过；发现原片、输出或处理配置变化则拒绝覆盖，不会静默重写。

旧根目录中的 `cell-*.mp4` 保留为历史资源。`tools/render-cinematic-videos.mjs` 仍可用于旧程序化场景研究，但已与正式视频清单解耦，只输出 `public/cinematics/procedural-preview/`；其制作记录写到 `test-results/cinematic-production/procedural-preview/`。它不能覆盖团队视频，旧的4秒/96帧规则仅属于这个预览工具。

## 播放约定

- `src/cinematic-manifest.js` 是正式映射及媒体元数据入口，只接受清单中的本地媒体路径。
- 在真实落点及到站转场之后播放，铺满游戏区域并完整保留画幅；片尾或跳过后再进入三选一，不在片中结算游戏资源。
- 声音遵循游戏偏好，发声时暂停四季配乐，片尾、静音或取消后按当前页面状态恢复。第8格无音轨，不显示无意义的片内声音按钮。
- 支持跳过、Escape、后台/弹窗/竖屏暂停与恢复；系统减少动态效果时跳过视频。
- 缺片或持续卡顿时展示真实帧静态备用，海报也失败才使用本地分镜；备用约3秒且可跳过，不调用API补片。

2026-09-12 的18组原版集成记录见 `test-results/team-cinematics/browser.json`。2026-09-13 的两片修补、当前单测及定向浏览器验收另见 `docs/影片局部修补-2026-09-13.md`；历史通过记录不当作新修补版的证明，也不等于公网或整版40格重新通关验收。
