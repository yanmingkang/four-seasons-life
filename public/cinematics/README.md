# 八个选择格的动画资源

本目录目前没有正式视频。游戏显示的 4 秒微缩场景是浏览器临时演绎，带“临时演绎 · 正式动画待替换”说明，不应作为小雨已交付的视频。

正式文件放入此目录，再在 `src/cinematic-manifest.js` 对应项中设置 `src:'/cinematics/cell-06.mp4'` 等本地路径。默认 `src:null` 不会发出探测请求或缺失文件请求。

交付文件名：`cell-06.mp4`、`cell-11.mp4`、`cell-13.mp4`、`cell-15.mp4`、`cell-18.mp4`、`cell-22.mp4`、`cell-27.mp4`、`cell-31.mp4`。

统一 16:9 横屏，建议 1920×1080，24 或 30 fps，H.264 MP4，每段 3–5 秒。视频默认为静音播放，请勿依赖声音传递关键信息。镜头里不要烧录 A/B 选项、属性变化或按钮；剧情后的交互卡片由网页负责。可另交付同名 JPG/WebP 海报并设置 `poster`。

详细分镜与验收流程见 `docs/动画交付清单.md`。无需上传密钥，不要把 API Key 放入本目录。
