# 四季回忆：游戏场景静帧

40 张 WebP 由本项目自己的 3D 场景生成，并非《初版.docx》的原图对照，也不是玩家操作过程的录像截图。

- 对应：文件名 `cell-01.webp` 至 `cell-40.webp` 与棋盘原始 eventId 一一对应。
- 渲染：复用 `mountScenePreview`、现有角色/场景/正交镜头/描边管线；固定场景时间 1.5 秒，1100×760，WebP 质量 0.9。
- 重新生成：保持本地 Vite 预览运行，执行 `node scripts/render-memory-scenes.mjs`。默认使用本机 4174，可通过 `MEMORY_PREVIEW_URL` 指向已有本机开发预览。
- 回忆册只读取本局实际已结算的 eventId；未经历季节不展示场景图。不将静帧当作玩家选择后的准确再演。
- 生成过程没有访问大模型 API，也没有截取玩家姓名、自由对话或账户信息。
- 美术来源与现有游戏保持一致，相关引用见项目根目录 THIRD_PARTY_NOTICES.md。

渲染代码或镜头修改后请重新生成。本批 40 张图片合计约 2.50 MB；回忆页按需加载当前图片，分享卡最多加载五张不同的图片。
