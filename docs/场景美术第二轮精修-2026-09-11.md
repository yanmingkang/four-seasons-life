# 场景美术第二轮精修

本轮对照现有原图修正结构和环境，继续使用可旋转的 Three.js 模型。原图文件不变，顶部资金、情绪居中、开局天赋说明及移除旧地标图卡的界面均保留。游戏规则和存档结构未改。

## 主要变化

- 体育馆：平环改为起伏曲面顶棚，增加屋面接缝、木肋和座席；办公组增加正侧分窗幕墙、窗内桌椅轮廓、入口雨棚和屋顶设备。
- 生煎铺：曲檐筒瓦、开放厨房、蒸笼、展示柜、巷墙和用餐陈设；露台增加玻璃花墙、木平台、伞骨、帆布座椅、花箱和有枝干的层叠树冠。
- 茶室：曲檐翼楼、木格门廊、茶桌、池塘小桥、前中后景园艺；咖啡书屋增加阅读侧廊、书架、屋顶窗、爬藤与秋树。
- 场景 8/10 增加楼梯门框、防滑条、站台结构梁、检票设施、候车座椅；14/16 增加生煎店灶台与露台花架；23/25/26 用分块墙体形成真实窗洞和窗外景深。书房增加秋景树、格纹沙发、几何浮雕墙画、前景矮柜和错落书籍。
- 材质由 64×64 升为 128×128 程序纹理，颜色、线性高度与粗糙度分别储存。木纹随长边铺设，补砖缝、瓦片弧面和织物经纬。近景保留像素边缘，远景使用 mipmap。
- 8 段过场按共享材质和光照重渲染为 1280×720、24fps、4 秒的 H.264。

## 渲染负担

合并场景环境中的静态物件，保留透明面排序、命名检查节点、角色和独立动画。相同近景渲染含阴影绘制次数：

| 场景 | 改前 | 改后 |
| --- | ---: | ---: |
| 楼道 8 | 336 | 106 |
| 高铁 10 | 330 | 160 |
| 生煎 14 | 658 | 376 |
| 露台 16 | 593 | 352 |
| 茶室 23 | 1012 | 258 |
| 书房 25 | 972 | 412 |
| 沙龙 26 | 868 | 406 |

这是实际 WebGL 绘制统计，并非实体手机帧率。增加模型细节后，重点室内仍减少约 41%–75% 绘制调用。
