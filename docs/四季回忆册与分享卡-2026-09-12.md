# 四季回忆册与分享卡

## 这次改动

结局默认从长篇报告换成可翻页的四季回忆册。参考 [网易云音乐 2024 年度听歌报告案例](https://www.epub360.com/h5anli/templatedetails/69159dbda222ba002d7c4a63/) 的“个人数据—四季片段—总结海报”阅读节奏，采用本游戏自己的画面、配色、文案与排版，不复制对方品牌素材。

1. 封面：本局称号、实际经历数量，以及一张真正停靠过的场景图。
2. 季节篇章：仅展示有已结算记录的季节，各选一个真实瞬间。优先留下陪伴选择，其次黄金选择或本季最后一次停靠。
3. 回看取舍：优先实际遇到的跨部门争议或关键选择，否则回看真实最后一条。没有统计犹豫时长，因此不写“犹豫最久”。
4. 带走方法：从实际记录对应的知乎讨论中整理一个小方法，作者与链接直接来自项目来源表；证据范围可展开。
5. 留念：四季缩略图、分享卡、完整文字手记和再走一程。

四季都有记录时共 8 页；仅经历一个季节时 5 页。提前结束也包含封面、取舍、方法与分享。未经历的季节在最后胶片页标记“尚未写下”，不配场景、不补剧情。无历史数据时显示空白入口且不能导出伪造回忆。

## 图像与真实性

- 主图取自当前游戏的 3D 场景。生成 40 张 1100×760 WebP，总计 2,502,300 字节，回忆页只加载当前所需图像。
- 这些是固定镜头的场景留影，不是玩家操作录像，也不声称重演了选择后的结果。没有重新加入用户不想要的“原图对照”。
- eventId 是场景映射依据，快速路线不会误用短路线序号。
- 选择和结果来自已结算 history，不重新计算历史资源，不修改游戏日志。完整结果可在详细手记查阅。
- 只使用该条历史记录已关联的 sourceId。方法为相关讨论整理，不加答主原话引号，不把现有搜索片段升级为全文核验。
- 不读取本机旧局方法收藏来冒充本局练习成果，不增加 API 来源核验或真实模型请求。

## 保留的功能

“详细手记”中仍保留原来的资源图、四季详情、固定十点回顾、后续影响、生活行动账、AI 总结、下一程继承提示，以及旧版完整人生长图导出。

默认回忆册直接使用本局记录，不依赖 AI。打开详细手记时保留原有 AI 总结入口与处理逻辑。游戏 3D 地图、三选项、选前收益隐藏、疲惫/休息与难度规则未改动。

## 分享边界与失败处理

- 新分享卡是 1000×2250 PNG，包含主图、四季实际选择、一道问题、一条方法与出处、二维码。
- 导出字段不含玩家姓名、自由练习对话、存档 journal 或凭据；二维码清除 URL 参数与片段。
- 127.0.0.1 等本地入口的二维码只包含题目，不标成外网试玩地址。HTTPS 链接通过格式检查不等于已部署或外网已验收。
- 图片只从包内固定路径加载，超时或加载失败时退回文字；生成失败可以下载完整手记。
- 原有 Blob URL 释放和 revision 防串页继续生效；取消生成不覆盖后来打开的页面。
