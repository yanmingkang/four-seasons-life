# 3D田园与地标接入 · 2026-09-10

本轮按用户澄清：游戏保持真实3D，参考星露谷式田园配色、像素材质与生活细节，而非改成2D。修改仅在本地，未提交或推送GitHub，也没有新开公网试玩。

## 怎么看

打开本机 `http://127.0.0.1:4173/`，Ctrl+F5刷新，欢迎页标记为「3D 田园版 · v4」。

点击「先逛逛 3D 小镇」进入四地标图册，选建筑后拖拽旋转、滚轮缩放。可切「查看全图」「跟随角色」。底部返回按钮结束观光；途中观光不移动玩家、不触发事件、不覆盖存档，自动出发设置也不改变。欢迎页未提交的昵称和天赋保留。

## 场景变化

- `world.js` 默认导出真实 Three.js / WebGL 的 `JourneyWorld`；旧2D模块留作历史实现，不再是正式入口。
- 29座程序化体积建筑：四个特色地标加统一的田园木屋、店铺、咖啡屋、工作坊。屋顶、侧墙、门窗、台阶、花箱都有立体结构；体育馆有真实开口而非屋顶贴图。布置按实际道路、水道和建筑占地避让。
- 图书馆保留红瓦、木墙、书窗和花箱；体育馆保留椭圆开放屋顶、看台和球场；城中村保留多层住宅、水箱、晾衣与植物；咖啡书摊保留绿白棚、书架、桌椅和遮阳伞。
- 刘看山为黑白立体角色，保留尖耳、大黑鼻、梨形身体、黑手黑靴与圆尾；增加脚底固定的呼吸、眨眼、张望和招手。动作、镜头、骰子和路线互相独立。
- 六面骰仍遵循原公平结果，3D动画展示结果，不反过来改变结算。重开/恢复/销毁取消旧动作；弹窗、隐藏、竖屏暂停，支持减少动态效果。
- 全图与地标镜头根据真实包围盒适配桌面和窄横屏，留HUD边距；旋转后保持用户镜头，跟随/重置可返回。
- 保留40/12路线、三选盲选、AI陪练、方法卡、知乎来源、v4存档、四季章节/天气/音乐。业务规则与模型路由未更换。

## 去底处理与Skill约束

按 imagegen Skill 的约束，获得用户明确许可后才运行本地图片处理。脚本为 `tools/prepare-landmark-cutouts.py`，仅移除与各格边界连通的浅中性棋盘背景，避免全局删白色破坏体育馆屋顶。此轮没有调用生图API。

原稿 `docs/art-drafts/life-landmarks-opaque-v2.png` 的 SHA-256：

`15b2400a8b018bcf42531b9ba19474424ddb97b89377680970b30173111f4802`

输出 `public/art/life-landmarks-v1.png`，1254×1254 RGBA。四格有效覆盖率约43.24%、40.41%、50.18%、36.55%，均有空白透明边界；体育馆保留45,868个高亮白色像素。已在奶油色/深绿色底下目检。原稿未修改。

图集只在可选图册展示，场景使用对应的程序化模型，不能把去底图片称为自动生成的3D模型。按照 stardew-style-image Skill 取其田园美术特征；该Skill默认2D的构图规则让位于用户明确的3D需求。生成稿并非《星露谷物语》原版素材。
