# 四季田园像素风与三选盲选

本轮按用户最新要求继续使用横屏 2D 像素世界。此前的 3D 模块保留，不再作为默认画面。参考图用于季节氛围、植被层次和乡间路线，不照搬鸟类角色或海报 UI。

## 美术依据与资产

使用 `stardew-style-image` 的视觉规范：俯视轻等距、明快田园色彩、清晰像素块、春樱／夏绿／秋橙／冬雪、小镇生活物件、少量中文木框 UI。不是仅给现有画面加模糊或像素滤镜，也不是官方《星露谷物语》素材。

内置 image_gen 生成四季树木图集，再用同一工具修正真实透明通道。最终资产 `public/art/season-trees-v2.png` 为 1254 × 1254 RGBA PNG，按 2 × 2 分格渲染。首次草稿的背景不透明，保留在 `docs/art-drafts/season-trees-v1.png`，不进入运行时目录。加载失败时保留程序绘制的树，不影响游戏进行。运行时无需生图 API。

生成提示词（技能模板按游戏素材图集用途调整）：

```text
星露谷物语风格像素农场生活模拟游戏树木素材图集
画风：Stardew Valley 风格 2D 像素艺术；俯视轻等距视角；清晰像素块、温暖鲜明田园色彩、低分辨率游戏画面感；不要3D渲染、写实摄影、高清插画、电影CG、矢量图标。
季节与时间：春夏秋冬，晴天正午。
场景地点：四季小镇的树木；输入图仅是像素色彩与树冠层次参考，不复制地图、文字、鸟和UI。
画面要素：樱花树、浓绿橡树、金橙枫树、覆雪松树、粗壮树干、枝条。
生活时刻：玩家路过树下采集；仅制作环境树木，不绘制玩家。
星露谷元素：花簇、层叠叶片、树根、树皮、积雪、枝桠。
素材规格：一张真正透明RGBA背景的正方形sprite atlas，严格2行2列等分；左上春樱树、右上夏橡树、左下秋枫树、右下冬松树。每格一棵完整独立树，树干基部对齐本格底部90%位置，树冠和树根完全在本格内，不相互接触，四周留足透明边距。四棵树比例一致。
像素规格：以每棵约128像素宽的可读游戏精灵绘制再最近邻放大；丰富有层次的叶簇和枝干、边缘清晰、避免平滑涂抹和散点噪声、不要附带草坪岛或地面，不要投影底板。
文字与UI：无文字、无UI、无Logo、无水印；背景必须透明，不画棋盘格背景。
```

透明修正提示：只移除背景棋盘格，保留四棵树、像素风、颜色与分格位置，输出实际 alpha=0 的透明 PNG，不以棋盘格模拟透明。

## 行为与选项

- 每个事件保留三个有区别的回应。选项列表不展示资源增减、结局、隐藏属性或辅助说明中的结果提示。
- 当前资源总量仍显示在 HUD；选择后明确显示实际资源变化、叙事反馈和手记。
- 费用不足仍可禁用无法承担的方案，使用不泄露具体后果的提示，不允许负余额或免费购买。
- 刘看山待机时有呼吸、眨眼、张望、招手与伸展，位置不变，不触发额外骰子或结算。弹窗、竖屏及后台暂停；减少动态效果设置下停止装饰动作。
- v4 存档改用独立键。旧键中的有效 v4 存档可复制迁移，原始记录保留，真正的旧版存档不强制套用新规则。

本轮不改变初始资源、六面骰概率、落点结算或游戏结束条件，不调用真实知乎业务 API 来测试，不部署公网。
