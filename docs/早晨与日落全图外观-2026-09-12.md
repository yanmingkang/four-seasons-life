# 早晨 / 日落：全图外观切换

参考用户提供的便利店交互视频与图片，在右上角加入双按钮。保留原有 3D 建筑、四季环境、刘看山和所有玩法。

## 玩家可见变化

- **早晨**：清亮天色、较高的太阳、柔和浅色阴影。
- **日落**：暖色光线、较长的阴影、偏暖的灯窗与灯笼、水面和天空配色同步变化。
- 约 0.95 秒渐变；镜头不重新定位。开启“减少动态效果”时立即切换。
- 跟随、全图、地标近景共用同一时段；路牌仍独立清晰显示，不对画布整体加滤镜。
- 手机横屏时按钮位于导航下方；竖屏提示显示时不可误触。
- 独立保存外观偏好，刷新、继续存档时仍保留，不写入游戏行动记录，不扣资源、不触发 AI 请求。

## 实现边界

- 仅两种时段，不新增晴雨雪按钮。四季仍由人生阶段与原地图决定。
- 改变整张实时 3D 地图，包含路线以外环境；独立剧情视频、场景卡内的单独布景、结局回忆静帧保留原有叙事光照。
- 保留一个太阳与环境光，不给每扇窗增加昂贵的动态点光源。
- 暖窗和路灯使用明确标记的世界内材质副本，避免污染独立场景的共享材质。全景批处理与遮挡淡出副本同步更新。
- 未启用 WebGL 的备用界面禁用切换，避免展示无效操作。

