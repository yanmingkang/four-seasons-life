# 结局称号与分享预览优化

本轮只优化称号判定、回忆封面的称号依据和分享预览，不修改骰子、资源数值、疲惫、事件选项或 AI 邀请机制。

## 称号与经历对应

- **东山再起患难伴侣**：记录中确实有低谷，其间有刘看雨的支持，随后在更晚的经历中恢复，结局没有冷战。不会因为完成旅程就自动授予。低谷按情绪不高于 30 判断；之后及结局恢复到至少 50，关系至少 55。自动关东煮必须同时匹配实际消耗与当次结算记录，单有道具库存不算经历。
- **重新出发的行路人**：确实经历低谷后恢复，但没有对应伙伴支持，不虚构“患难伴侣”。
- **小步经营探索者**：替代夸大的“商界巨舰独行客”。要求实际开启合作、验证小样、试运营并收到后续营业结算，不能仅靠一次高薪邀约或余额解锁。
- **小城慢调生活大师**：实际选择留在本地，之后至少两次选择休息或安排边界，并在结局保有情绪余量。
- **琴瑟和鸣破局者**：需要实际共同生活/交流、专业增长记录，并满足既有专业、关系和非冷战条件。
- 没有充分证据时使用 **四季行路人**，不强行推断性格或编造经历。

封面用一句本局真实选择替换泛泛副标题。小横屏标题与留白已压缩，依据无需滚动就能完整看到；没有额外堆叠说明段落。

### 对旧记录的回归

重放此前 15 局真实试玩记录，不是重新试玩 15 局。全部恢复后的游戏状态与原记录一致。

原称号为：12 局患难伴侣、2 局慢调、1 局商界；修正后为：13 局四季行路人、2 局慢调。这个样本没有满足新条件的经营或共患难经历，因此不为称号多样性虚构奖励；各局封面仍展示各自的真实选择。

新称号可以用于重新打开已保存旅程的结局，不需要清空存档。此前已下载的图片不会自动改变，需要重新生成。

## 分享预览

- 默认可读宽度，桌面实测 800 像素，844×390 横屏实测 762 像素。
- 中间区域独立滚动，顶部缩放/关闭、底部下载/返回始终保留。
- 点击“整张预览”查看全图，再点“放大细看”恢复阅读；图片本身也可点击切换。
- 键盘操作、Escape 关闭、返回回忆册和重复打开均可用。
- 导出图片的尺寸与内容绘制流程不变：四季回忆卡 1000×2250，旧详细报告按内容生成相应长度。
- 分享 URL 在返回或关闭后回收；本地二维码仍明确不是公网试玩链接。

## 验证结果

- 全量测试：430 项，429 通过、1 项原有跳过、0 失败。
- 生产构建通过，仍有既有的大体积主包提示，本轮没有声称解决首次加载体积问题。
- 生产浏览器 4 个分享场景通过：完整结局桌面/横屏、提前结束桌面、旧详细报告桌面。
- 另检查 667×375 封面，称号依据可见；844×390 封面同样无裁切。
- 下载尺寸、两态缩放、滚动、固定按钮命中、Tab/Enter/Space/Escape、重复打开与 12 个分享 URL 回收通过，未发现页面 JavaScript 错误。
- 原生浏览器 Tab 可进入浏览器工具栏，测试允许该行为，但验证不能让被模态窗口遮住的游戏控件获得焦点或被触发。
- 浏览器验证使用隔离存储和录制的合法存档，不改用户存档；API 被隔离，没有调用真实模型。不能据此声称实时 AI 或公网试玩已验收。

本地游戏已通过原启动器恢复至 `http://127.0.0.1:4173/`，健康检查通过。没有发布公网、上传 GitHub 或修改账号配置。
