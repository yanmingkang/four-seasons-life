# 结局独立画面与同风格渲染

## 这轮修改

用户指出“回看取舍”和“带走的方法”连续展示同一张病房全景，并明确要求保持现有游戏画风。

- 取舍页继续保留本局实际经历的场景留影。
- 带走页按实际选定的知乎方法来源使用陪伴／沟通／成长／休息主题画面；第 18 格的陪护安排对应陪伴构图。
- 回忆册封面使用独立四季与笔记本构图，不再重复代表事件的照片。
- 场景留影标记与主题画面标记分开；主题画面不是新发生的剧情，不改变旧存档、数值、选择、来源或已到访记录。
- 暂未到达的季节仍保留留白，缺少来源时不补写答主建议；图像加载失败原位显示文字，不再回退重复的场景照片。
- 当前分享卡仍保留本局真实场景照片，本轮没有重写分享卡内容。

## 画风与文件

早期 imagegen 写实静物草稿已被用户否决，未复制到游戏、未接入、未发布。最终图片是可编辑的原生 Three.js 场景重新渲染，不是对草稿做本地滤镜、裁切或修图。

最终复用 `createLiuKanshan` 的实际模型、游戏 `pixelTexture` / `applyReferenceSurface` 材质、`createPixelSceneCamera` 正交构图、2px 像素边缘、ACES 曝光 1.12 和场景阴影。新场景仅作为预渲染图片使用，不在玩家结局中新建 WebGL 实例。

五张资源均在 `public/art/ending-v1/`，1200×800 PNG，合计约 1.27 MB：

- `cover.png`：四季小花园与打开的回忆册。
- `accompany.png`：双座、共用笔记本与刘看山。
- `communicate.png`：沟通桌、无字便签与笔记。
- `grow.png`：书架、笔记与新苗。
- `rest.png`：窗边座椅、暖灯与留白。

图像为主题意象，不宣称玩家实际到过这些新增构图。木地板、人物和低多边形外观保持与原游戏一致。

复现：`node scripts/render-ending-art.mjs`。只使用随机端口的本地 Vite 与隔离浏览器，阻断外网和业务 API，结束后关闭临时服务；不影响原 4173 服务。源码为 `src/ending-memory-scene.js`。

## 验收入口

- `tests/memory-art.test.mjs`：医院图去重、真实来源映射、空／提前结束历史、失败降级。
- `tests/ending-memory-scene.test.mjs`：五种原生几何及实际角色模型。
- `tests/memory-art-assets.test.mjs`：五张图片不同、尺寸与发布白名单完整、体积受限。
- `tests/memory-browser.mjs`：完整／提前结束／短局／医院专项，电脑与小横屏，逐页图片、导航、来源与分享下载；测试存档仅用于定位界面，不计为新的完整试玩局。
- `tests/memory-browser.mjs --pages`：固定生产域名的医院与提前结束专项；业务 API 明确模拟 503，不消耗真实游戏 AI 额度。

测试使用独立浏览器存储，不读取或修改用户真实存档。浏览器测试代码已同步正式版“走进我的四季 → 翻开上次回忆”的入口流程。
