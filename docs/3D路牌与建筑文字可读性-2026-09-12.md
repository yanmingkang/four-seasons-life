# 3D 路牌与建筑文字可读性

本轮仅优化地图文字，不修改玩法、数值、建筑几何、四季环境或刘看山。依照 Sites 的可读性与响应式检查要求，在现有本地项目中迭代，没有重新搭建或发布站点。

## 已实现

- 新增独立 CSS 分辨率文字层。中文路牌和建筑名称不再依赖低分辨率 WebGL 画布，使用微软雅黑／苹方／Noto 中文无衬线字体，桌面 15 px，短横屏 14 px。
- 3D 路牌保留实体结构和编号；中文名称在清晰标签中显示。入口及终点文字也迁入独立层；地面编号纹理改为线性过滤和 mipmap。
- 实体建筑使用现有真实名称与三维锚点，标签附短引线。聚焦建筑时只显示当前建筑名称；近景优先当前位置及附近路牌，避免同站点重复名称。
- 总览优先保留四季与人生阶段标签，再按空间余量显示建筑名；桌面总计最多 14 个标签，短横屏最多 8 个，不是同时铺满 40 个名称。
- 标签避让 HUD、角色及其他标签，限制偏移，裁除相机背面／视口外锚点。总览代理合批不导致名称丢失。
- 不拦截拖拽或滚轮；行走时保留被动标签，掷骰、选项卡、对话框及季节转场时隐藏。关闭弹窗后恢复。
- 短路线编号随原有路线更新。通过小镇查看短路线之外的建筑时，聚焦名称仍然可见。
- 销毁地图时清理标签 DOM，没有额外动画循环或输入监听。

## 验收结果

`npm run build` 成功；`npm test` 共 372 项，371 通过、1 项原有跳过、0 失败。仍有现有大型主资源包的体积警告，本轮未扩展为资源拆包任务。

`tests/world-signage-browser.mjs` 在开发服务及 `--production` 独立生产服务中均通过。Chrome 真实 WebGL（ANGLE D3D11），检查 1440×900 / DPR 1 与 844×390 / DPR 2 两种布局，每种 12 个画面检查，共 24 个；不是 24 局完整游戏。

覆盖：春夏秋冬代表建筑（第 1、18、29、40 格）、总览与放大、跟随视角、拖拽旋转、滚轮缩放、弹窗关闭恢复、实际掷骰到第一格并三选一、短路线外建筑聚焦。四季总览标签均保留；标签无互相重叠、无越界、无像素化 CSS、字号不低于 14 px；浏览器脚本错误为 0。

只进行了每种布局一回合真实 UI 交互，不是全程四十格复验。所有业务 API 在隔离浏览器中拦截为离线测试响应，外部请求阻断，不证明真实 AI 回答或额度可用。

验收产物：`test-results/world-signage/report.json` 及同目录截图。报告最后一轮为生产构建验收。原有 4173 游戏服务未被停止或替换，首页与新文字模块均返回 HTTP 200。没有上传 GitHub、外网部署或修改用户浏览器存档。
