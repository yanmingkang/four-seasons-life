# 手机横屏适配 · 2026-09-14

## 修改范围

针对手机内置浏览器上下工具栏挤占高度，欢迎卡片下方被裁切的问题：

- 使用 VisualViewport 同步实际可视高度、宽度与偏移，兼容不支持该 API 的浏览器回退；响应工具栏、键盘、旋转和返回页面。保留系统双指缩放，不锁定用户缩放。
- 封面的昵称、三种心态、上局继承合并为一个可滚动设置区；「走进我的四季」独立固定在卡片内底部，保留所有选项和说明。昵称与练习输入使用至少 16px 字体。
- 矮屏封面暂不展示尚未开始的资源栏和旅行工具；欢迎/结束卡不再覆盖早晨/日落按钮。开始旅程后原控件恢复。
- 对话框、视频控制栏、主控件留出逐边安全区，避免刘海和底部横条；练习输入弹出键盘时，弹窗仍受实际可视高度约束，关闭按钮保持可用。
- 回忆册内容独立滚动、翻页栏留在下方，四季缩略图不再盖住导航。分享预览和下载操作保留各自的滚动/固定区域。

没有修改：三维建筑/角色、随机骰子、数值难度、三选项、存档格式、强制知乎登录、OAuth 回调、AI 模型或配额。仍是横屏游戏，竖屏提示旋转并暂停旅程。
