# 美术与知乎来源改进

本轮直接修改了可玩的 3D 版本。打开本机 http://127.0.0.1:4173/ ，从「小镇地标」选择地点，在「走进场景」「建筑外观」之间切换；拖拽旋转、滚轮缩放，「原图对照」保留用户提供的原始图。

## 美术

- 共用的窗、门、屋顶增加分层木框、窗台、窗扇、檐口、山墙和暖色室内细节；木材、砖墙、石铺地与屋瓦按实体尺寸铺设纹理，减少拉伸。贴图近景保留像素颗粒，远景使用 mipmap 减少闪烁与噪点，增加微弱表面凹凸。
- 图书馆修正交叉屋顶与山墙，增加花箱、栏杆和分层绿冠；城中村增加生活器物、空调格栅、晾衣与线缆；文创园改善院落退距、露台咖啡、铁梯、玻璃阁和爬藤；温泉增加针叶、积雪、水口、涟漪与石路；星图殿增加柱头、穹顶线、星座和庭院嵌砖。
- 事件空间补充墙裙、线脚、实体褶帘和灯具；医院补床护栏、推车、设备带，浴室补排风、淋浴、搁架、洗漱道具与篮子，书房补连续木纹、地板、书脊标签、抽屉和台灯。重点8个过场与其余事件共用细节保持一致。
- 建筑静态部件按材质合并，保留真实 UV、位置、厚度和透明玻璃排序；室内重复静态细节使用实例绘制，动态角色与剧情道具保留独立动作。修复预览阴影资源释放。外观预览调低环境泛白，加入冷暖光区分层次。
- 8段 MP4 已按新场景重新渲染，各1280×720、24fps、96帧、4秒，总计5,869,325字节。仍是 Three.js 场景渲染，所有片尾保持待选择状态。

本轮是对原图建筑结构、材质和环境细节的进一步三维改编，仍未达到每张原图逐细节复刻的程度。参考图原文件未修改；大地图足迹、40格路线、选项与存档规则保持原逻辑。
