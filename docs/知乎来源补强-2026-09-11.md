# 知乎来源补强交付

当前来源库 37 条，40 格实际使用 33 条独立知乎回答或文章；本轮新增 16 条，当前使用中缺作者为 0。原来由缺作者异地回答支撑的 4 格，分别换成已核对显示作者的异地规划、家庭沟通、购房预算和小协作来源。旧 ID 与缺口照实保留，不借新资料修改旧记录的出处。

18 处映射获得更贴近事件的依据，包括租房整理、转正、项目复盘、作品集、记账、接单范围、店铺选址和工资材料整理。经验册改为“条独立来源”，说明多格可共用同一来源，不能理解为 40 篇独立真实案例。

本轮还逐条对照了 16 条新来源的 `idea` 和事件适用条件，核对以下事项：

- 归档短片段直接支持展示中的具体细节；异地追剧和通话、接单范围、付款节点等分别保留对应原句。
- 不连续原句用明确的省略号分隔，在证据 JSON 中逐段保留 `excerptSegments`，不会把拼接内容呈现为连续原文。
- 删去最小证据没有覆盖的购房装修亲历、家庭规划细节和带教差异等额外表述。
- 购房仅采用支出类别，不采用税率、房价、首付或月供比例；欠薪仅采用材料整理与专业咨询，不推导劳动关系、证据效力、时效或金额。
- 每条保留元数据、UTC访问时间、短片段、解释、适用边界及返回文本摘要哈希；只保留任务必要内容，不将整个搜索响应写入项目。

全文仍有明确限制：当前 32 条为搜索片段，1 条为此前公开搜索返回的正文（未另行登录核验）；本轮新增完整原文核验 0 条。两次直接访问新社区原文均返回 HTTP 403，之后没有重复请求，没有把搜索结果改称“已读全文”。赛事知识详情有正文截断，本轮未采用，也未扩大原文链接白名单。

详细出处与采用范围见 [来源补强报告](../references/来源补强-2026-09-11.md)；可核对原句见 [证据记录](../references/zhihu-evidence-2026-09-11.json)。
