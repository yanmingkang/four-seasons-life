# 道具与结局报告核对

核对依据：用户提供的 8 件道具表、失败结算与继承、成功报告及 10 大选择点回溯设计截图。

## 已补齐的功能

| 项目 | 当前实现 |
| --- | --- |
| 留痕备忘录 | 准备后免疫下一次职场负面情绪；稳健天赋的首次甩锅自动保护保留。提前手动使用会消耗该份库存。 |
| 物理降噪耳塞 | 装备后持续 3 次事件结算，免疫第 8、22 格流言或攀比的负面情绪；其他事件也消耗持续次数。 |
| 咖啡续命兑换券 | 100 元和 1 张券恢复 20 点情绪，每回合一杯，不超过上限。 |
| 深山温泉度假卡 | 限秋冬，10,000 元，情绪上限 +10 并回满；本局道具提高的上限最多 180。 |
| 前辈长谈便签 | 展示当前每个选项的资金、情绪、专业变化、门槛和天赋/道具影响，并列出思考问题。 |
| 劳动合同法务指南 | 准备后，下一次指定争议事件负面情绪减半。 |
| 非暴力沟通回执卡 | 冷战时使用，解除冷战并恢复 20 点关系，最多 100。 |
| 深夜温热关东煮 | 事件结算后情绪低于 20 且有库存时自动消耗 1 份，恢复 35 点，优先于树洞保护；仍保留低情绪时手动使用。 |
| 行囊说明 | 8 件道具均显示类别、效果和使用方式，可展开查看场景、获取途径及限制；展示自动守护、树洞次数及持续效果。 |
| 树洞与失败 | 没有关东煮可用时，情绪归零可触发每局一次树洞保护，回到 15 点；保护耗尽后再归零则结束。 |
| 失败报告 | 泛黄“未竟之书”，根据实际季节和最后选择生成独白；展示相关知乎原句、作者、链接及核对范围。 |
| 下一局积累 | 失败获得固定 +10 初始情绪与上限；成功获得 +5 专业、+5 情绪与上限。两类都获得时为 +5 专业、+10 情绪与上限，不反复叠加。结束即保存，出发页可选择是否携带。 |
| 成功报告 | 本局三维资源雷达、四季分章、真实选择与结果、季节收支、四种既有称号及成就图鉴。 |
| 10 大回溯 | 固定第 6、10、13、15、18、20、22、27、30、31 格。亲历展示选择、资源前后值和已发生后续；越过和未抵达明确留白。较长后续可折叠。 |
| 导出分享 | 成功/失败均可下载竖版 PNG 人生长图，含雷达、称号、箴言、10 节点、知乎来源署名和二维码；文本手记也含完整回溯。 |

## 与截图设想的明确差异

- 没有可支撑“真实胜率分布”和“最佳人生选项”的统计数据。便签展示可复核的本局规则与相关经验，不生成虚构比例。
- 法务指南不额外发放“必得 N+2”。第 31 格原有剧本补偿继续由玩家选择和游戏规则结算，不声明现实法律保证。
- 10 个指定节点都会列出，但骰子越过的格子不会被写成亲历。
- 四种称号保留既有资源、关系及路线条件，图鉴可读具体条件；没有改成现实人格测评。
- 本机二维码编码一道游戏问题，不把 localhost 宣称为外网试玩入口。公开 HTTPS 入口仍会去掉查询和片段后使用。

## 兼容与验证

新开局使用生活规则 schema 2；schema 1 的旧存档按原规则重放，维持原有关东煮、耳塞等结算结果。继承凭据经重放验证，双类遗产完整局抽查 5,627 字节，低于 8,192 字节限制。

- 全量测试：342 项，341 通过，1 项原配置跳过，0 失败。
- 生产构建通过；保留既有主包较大的构建提示。
- 主界面浏览器验收通过：道具说明及便签预览、伴侣、刷新续玩、自动关东煮、树洞保留、失败报告、下载手记、长图、重开继承及取消继承、两版旧局兼容。
- 报告在 1440×900、844×390、667×375 检查无横向溢出；资金和情绪栏居中，窄横屏工具按钮分两行。
- 示例 PNG：成功 900×3799，失败 900×3304；长文压力示例 900×6708，无文字画布越界。
- 所有浏览器验收拦截模型和搜索请求，没有调用真实模型，也没有修改玩家浏览器存档。
