# 刘看山到站、掷骰与起步朝向修复

## 原因

旧 `place()` 根据动作阶段切换路径朝向和反向朝向。掷骰结束、行走结束和取消流程又直接写入 `heading + Math.PI`；同位置刷新游戏状态也会重新摆正姿态。因此到站翻转、投骰转正、投完再翻转、起步又转正。自动跟随相机还会两次立即回位，加重突兀感。

## 本轮修改

- 到站、投骰结束与取消不再强制转半圈，保留前进朝向；同位置选择/结算更新不重置身体朝向。
- 道路方向与角色可视朝向分开，行走时以最短转角平滑追踪，跨越正负 180° 不额外绕圈。
- 起步或投骰前需要调整时，先原地平滑对正；到站仅平滑收尾，不掉头看向身后。骰子飞行过程中不转动角色根节点，保持手和投掷方向一致。
- 转身复用可暂停、可取消的行走时钟；取消不会误报已到达，加载失败也会释放动作锁。
- 自动跟随回位采用过渡，手动“重置视角”仍立即生效。
- 朝向使用实际活跃帧间隔，并限制每次最多按 100 ms 推进；环境动画仍保持原来的 50 ms 上限，改善低帧率弯道跟随。
- 本轮只修改角色/相机动作及相关测试，不改变骰子概率、事件、资源数值或存档格式。
