## 实际播放与声音

1. 刘看山完成掷骰和行走，按落点更新游戏状态；跨季章节和到站转场完成后才播放对应视频。
2. 视频覆盖游戏可用区域，以 `object-fit:contain` 完整展示原构图；不同屏幕可能留边，不拉伸或剪掉镜头。视频中不叠加选择卡或游戏收益。
3. 正常播放等待媒体的片尾 `ended` 事件，再经过约220毫秒的收尾转场，进入三个选项；不按清单时长倒计时截断长片，也不重写游戏资源。
4. “跳过，进入选择”和Escape均可提前结束；系统减少动态效果时直接跳过。播放中不允许再次投骰。
5. 视频声音跟随游戏声音偏好；有声播放时暂停四季背景音乐，片尾、静音、取消后按当前页面状态恢复。浏览器拒绝自动有声播放时，静音继续画面，并允许玩家主动重试开启声音。第8格无音轨，不显示片内声音开关。
6. 后台、弹窗或竖屏暂停媒体及有效计时，返回可玩状态继续。重新开局、退出或旧回合失效会取消播放、释放媒体和监听器，过期回调不能展示旧选择卡。

## 加载失败与备用

- 开始播放前最多等待4.5秒有效时间；开始后连续3.5秒无进展进入备用，暂停期间不计入这些预算。
- MP4缺失、无法解码、无法播放或持续卡顿时，优先保留该片真实画面海报，显示简短情境作为静态备用；海报也失败才使用现有本地微缩分镜。
- 备用约3秒后进入选择，也可立即跳过。它不是成功播放原视频，不能将备用截图当成正式视频验收。
- 不调用模型补片、不切换API供应商、不消耗玩家数值或改变骰子结果。

## 导入和资源保护

从项目根目录执行：

```powershell
node tools/import-team-cinematics.mjs
```

该工具固定读取桌面“动画”目录中本表8个原文件名，并使用本机ffmpeg/ffprobe；不是扫描任意文件夹的批量上传器。换电脑前应先核对工具中的输入及依赖路径。处理步骤包括原片哈希、兼容转码、整片音视频解码、帧数与时长一致性、音轨、来源元数据、faststart和实际帧封面检查，全部完成后才将新媒体目录整体发布到公开资源区。

导入证明：`test-results/team-cinematics/media.json`。每段前、中、后画面接触图位于同目录 `cell-NN-contact.jpg`，属于非公开验收材料。已有输出及报告一致时再次执行只验证并跳过；原片、输出或配置变化时拒绝覆盖，应先人工核对并明确新版本目标。

旧的 `public/cinematics/cell-*.mp4` 留作历史资源，包括不再引用的 `cell-13.mp4`。`tools/render-cinematic-videos.mjs` 保留，但只向 `public/cinematics/procedural-preview/` 输出旧程序化预览，制作记录也隔离到 `test-results/cinematic-production/procedural-preview/`；它不读取正式团队片单，不能覆盖本轮视频。该旧预览工具自身的4秒/96帧规则不适用于当前播放器。

## 集成接口

```js
import {playCinematic,cancelCinematic,getCinematic} from './cinematics.js';
import './cinematics.css';
import './cinematic-player.css';

if (getCinematic(event.cinematicId || '')) {
  await playCinematic(layer,event.cinematicId,{
    isCurrent:()=>token===activeToken,
    isPaused:()=>modalOpen || document.hidden || portrait,
    isSoundEnabled:()=>sound,
    onSoundToggle:()=>setSound(!sound),
    onAudioChange:active=>pauseBackgroundMusic(active),
  });
}
// Re-check the round token and pause state before showing the choice card.
// Restart / exit:
cancelCinematic(layer);
```

示例回调由宿主提供；背景音乐恢复还须尊重弹窗、后台、竖屏、用户静音和结局状态，不能在收到 `false` 时无条件播放。正式映射由 `src/cinematic-manifest.js` 管理，只接受白名单中的本地视频和封面路径；第13格标记为无视频，不能仅凭旧文件还在磁盘就重新触发。
