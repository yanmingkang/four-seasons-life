## 技术交付规范

- 横屏 16:9；建议 1920×1080，最低 1280×720。24 或 30 fps，所有片段保持一致。
- 每段 3–5 秒，建议 4 秒；H.264 MP4，适合网页播放，单段建议不超过 4 MB。
- 现有刘看山形象须保持一致。巴比特风格的具体造型与材质由首支样片确认；不要把临时代码分镜当作最终风格批准。
- 不烧录 A/B 选项、金币数值、爱心数值或按钮。网页在片段结束后展示可操作的选项卡。
- 默认静音并支持内联播放。不使用未经授权的音乐、第三方水印或外链素材。
- 文字和角色脸部距画面边缘至少 8%，适配浏览器与窄横屏；动作重点靠近画面中部。
- 可交付同名 JPG/WebP 尾帧或封面。角色被截断、字体溢出、过度闪烁均需返修。

## 接入与防卡死机制

1. 文件放进 `public/cinematics/`，对应清单条目设置 `src:'/cinematics/cell-06.mp4'`；保持不存在的视频为 `null`。
2. 角色到达地点、完成到站转场后，才调用 `playCinematic`。片段或临时演绎结束，才打开选项卡，播放中禁止重复投骰。
3. 提供可键盘操作的“跳过，进入选择”；Escape 同样可跳过。系统“减少动态效果”开启时直接进入选项。
4. 切后台或打开暂停弹窗时，动画和有效计时暂停。重新开始或旧回合失效时立即取消，并释放视频资源。
5. 本地视频不存在、无法解码、播放被拒绝或长时间无进展时，切到临时分镜，不切换任何模型供应商，也不调用模型生成补片。
6. 3 秒以下视频会保留结尾画面到最低时长，5 秒以上视频按上限结束；用户主动跳过与减少动态效果不受最低时长限制。

## 集成 API

```js
import {playCinematic,cancelCinematic,getCinematic} from './cinematics.js';
import './cinematics.css';

if (getCinematic(event)) {
  await playCinematic(layer,event,{
    isCurrent:()=>token===activeToken,
    isPaused:()=>modalOpen,
  });
}
// Re-check the round token before showing the choice card.
// Restart / exit:
cancelCinematic(layer);
```

事件可携带 `cinematicId:'cell-06'` 或 `cell:6`。清单只接受这 8 个格子；不支持任意外部视频地址。
